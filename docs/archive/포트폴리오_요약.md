# 🚀 TinyPilot 컨테이너화 프로젝트

> **레거시 시스템 리버스 엔지니어링 및 컨테이너 경량화 전문성 입증**

---

## 📌 한 줄 요약

문서화되지 않은 하드웨어 종속 레거시 시스템을 리버스 엔지니어링하여 표준 컨테이너로 현대화하고, Multi-stage Build로 **89.2% 경량화**를 달성한 DevOps 프로젝트

---

## 🎯 핵심 성과

### 1️⃣ 컨테이너 경량화 (실측 검증 완료)

```
┌──────────────────────────────────────────────┐
│  📦 TinyPilot:  2.84 GB  →  277 MB  (90%)   │
│  📹 uStreamer:   755 MB  →  110 MB  (85%)   │
│  💰 총합:       3.59 GB  →  387 MB  (89%)   │
└──────────────────────────────────────────────┘

✅ 배포 시간: 6분 → 32초 (94% 단축)
✅ 스토리지 비용: 89% 절감
✅ 컨테이너 시작: 85% 개선
```

**기술적 접근**:
- Multi-stage Build로 빌드 환경과 실행 환경 완전 분리
- 빌드 도구 555MB 완전 제거 (gcc, nodejs, npm 등)
- 개발 패키지를 런타임 패키지로 교체 (70MB 절약)
- 불필요한 파일 정리 (캐시, 테스트, dev-scripts 제거)

### 2️⃣ 리버스 엔지니어링 및 시스템 현대화

**도전 과제**:
- 문서화 없는 베어메탈 기반 시스템
- 커널 레벨 하드웨어 직접 제어 (`/dev/hidg*`, `/dev/video0`)
- 컨테이너 환경 공식 지원 없음

**해결 과정**:
- 코드베이스 완전 분석 및 의존성 매핑
- 불필요한 기능 제거로 코드 30% 경량화
- 마이크로서비스 아키텍처로 재설계
- Docker Compose 기반 자동화 구현

### 3️⃣ 커널 레벨 버그 해결 (프로젝트 무산 위기 극복)

**문제**: 컨테이너 환경 이관 후 마우스 비정상 동작 (우클릭 반복, 커서 고정)

**디버깅**:
```bash
# 1. HID 패킷 덤프로 데이터 불일치 발견
sudo xxd /dev/hidg1  # 7바이트 전송

# 2. 소스 코드 리버스 엔지니어링
struct.pack('<BhhBB', ...)  # TinyPilot은 7바이트 전송

# 3. 커널 설정 확인
cat report_length  # 5바이트 기대 ← 불일치!
```

**해결**: 하이브리드 HID 디스크립터 설계
- 7바이트를 수신하되 마지막 2바이트를 패딩으로 처리
- TinyPilot 애플리케이션 코드 수정 없이 커널 레벨에서 해결
- 자동화 스크립트 작성으로 재현 가능성 확보

## 🎤 면접 대비 핵심 포인트

### Q1: "어떻게 89%나 경량화할 수 있었나요?"

**답변**:
```
Multi-stage Build를 활용했습니다. 빌드 환경과 실행 환경을 완전히 분리하여,
gcc, nodejs, npm 같은 빌드 도구(555 MB)를 최종 이미지에서 완전히 제거했습니다.

또한 -dev 패키지 대신 런타임 라이브러리만 포함하고, 캐시 파일과 테스트 코드를
삭제했습니다. 최종적으로 3.59GB → 387MB로 89.2% 경량화에 성공했습니다.
```

### Q2: "가장 어려웠던 기술적 도전은?"

**답변**:
```
컨테이너 환경으로 이관 후 마우스가 완전히 작동하지 않아 프로젝트 무산 위기였습니다.

xxd로 HID 패킷을 덤프하여 TinyPilot이 7바이트를 전송하는데 커널은 5바이트를
기대한다는 것을 발견했습니다.

USB HID Report Descriptor를 커스터마이징하여 7바이트를 수신하되 마지막
2바이트를 패딩으로 처리하도록 해결했습니다. 애플리케이션 코드 수정 없이
커널 레벨에서 해결한 것이 핵심이었습니다.
```

### Q3: "이 프로젝트에서 배운 점은?"

**답변**:
```
1. 컨테이너 경량화의 중요성과 구체적 기법을 체득했습니다
2. 문서가 없어도 코드와 시스템 동작을 분석하는 리버스 엔지니어링 능력
3. 커널 레벨 디버깅을 통한 근본 원인 분석 능력
4. 레거시 시스템을 현대적 아키텍처로 전환하는 설계 능력

이 경험은 실무에서 기존 시스템을 컨테이너로 마이그레이션하거나
성능 최적화가 필요한 상황에 직접 적용할 수 있습니다.
```
